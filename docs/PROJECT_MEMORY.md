## 1. 🏗️ Ecosistema y Estructura General

Este repositorio aloja el sitio web corporativo y de adquisición de clientes para **FlexOS Control 2026 / FlexOS Suite PRO V6**, el sistema ERP/MES vertical diseñado para la industria flexográfica, de conversión de empaques y etiquetas.

### Stack Tecnológico
* **Framework:** Next.js 16 (App Router) sobre React 19.
* **Estilos:** Tailwind CSS v4 con variables CSS nativas, utilidades de *glassmorphism* y tema oscuro industrial (`#0b1120`, azul `#0ea5e9`, esmeralda `#10b981`).
* **Iconografía:** Lucide React con optimización de importaciones (`optimizePackageImports` en `next.config.ts`).
* **Mailing / Leads:** Nodemailer integrado con Google Workspace SMTP para envío de solicitudes de demo y postulaciones al Programa MVP.
* **Analítica & SEO:** Google Analytics (`G-DRRBQDL1WV`), Schema.org (`SoftwareApplication`), sitemap dinámico (`src/app/sitemap.ts`) y robots (`src/app/robots.ts`).
