**FlexOS Technologies** es una firma de ingeniería tecnológica de espectro completo especializada en el desarrollo de infraestructura de software crítico, sistemas empresariales en la nube, aplicaciones móviles nativas y hardware especializado para la automatización e Industria 4.0.

## 🛠️ Stack Tecnológico del Proyecto

Este portal web corporativo está construido con los estándares más avanzados de rendimiento web:

* **Framework:** [Next.js 16](https://nextjs.org/) (App Router sobre Turbopack)
* **Librería UI:** [React 19](https://react.dev/)
* **Estilos:** [Tailwind CSS v4](https://tailwindcss.com/) con diseño *Glassmorphism* y paleta *Industrial Mission Control*
* **Animaciones:** [Framer Motion](https://www.framer.com/motion/) para transiciones dinámicas y KPIs flotantes
* **Tipografías:** `Space Grotesk` (títulos y display), `Inter` (cuerpo) y `JetBrains Mono` (telemetría y código)
* **Iconografía:** [Lucide React](https://lucide.dev/)
* **Backend de Contacto:** [Nodemailer](https://nodemailer.com/) conectado a Google Workspace SMTP con selector interactivo multi-proceso
* **Acciones Flotantes:** Burbuja interactiva de WhatsApp corporativo (+52 33 4874 2297) y botón de retorno rápido al inicio (*Scroll to Top*)
* **SEO & Datos Estructurados:** Schema.org (`Organization`, `SoftwareApplication`), Open Graph, sitemap dinámico y robots.txt

## 🏁 Inicio Rápido para Desarrollo

### Prerrequisitos
* Node.js 18.18+ o Node.js 20+
* Gestor de paquetes `npm`

### 1. Clonar el repositorio:
```bash
git clone https://github.com/zaragozagdl/FlexosTechLandingPage.git
cd FlexosTechLandingPage
```

### 2. Instalar dependencias:
```bash
npm install
```

### 3. Configurar variables de entorno (opcional para envíos de correo):
Crear un archivo `.env.local` basado en `.env.example`:
```env
SMTP_USER=contacto@flexostechnologies.com
SMTP_PASS=tu_clave_de_aplicacion
DEST_EMAIL=ventas@flexos.tech
```

### 4. Iniciar el servidor de desarrollo:
```bash
npm run dev
```
Acceder a [http://localhost:3000](http://localhost:3000) en el navegador.

### 5. Compilar para producción:
```bash
npm run build
npm start
```
